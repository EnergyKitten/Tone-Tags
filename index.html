Tone Tag Guide

A little guide to understanding tone through text.

How to use tone tags

Add a tag at the end of a message, like “You're so silly /lh” or “Are you okay? /genq”. Tags are optional and never excuse unkind behavior.

♡ There is no universal official list. Less common tags and context markers may have different meanings in different communities. Ask when unsure. This guide works completely offline.
